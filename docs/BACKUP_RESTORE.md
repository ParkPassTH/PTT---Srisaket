# คู่มือสำรองและกู้คืนข้อมูล

## สำรองข้อมูล

1. เข้าสู่ระบบ Dashboard
2. เปิดเมนู **รายงาน**
3. กด **ดาวน์โหลด Backup**
4. เก็บไฟล์ JSON ในพื้นที่ที่จำกัดการเข้าถึง เพราะมีข้อมูลเกษตรกรและหลักฐาน ICS

ไฟล์ประกอบด้วย schema version, วันเวลาสร้าง, ข้อมูลทุก entity และ SHA-256 checksum ระบบบันทึกเหตุการณ์ `BACKUP_EXPORT` ทุกครั้ง

## ตรวจและกู้คืน

1. เลือกไฟล์ Backup JSON ในหน้าเดิม
2. รอข้อความว่าไฟล์ถูกต้องและตรวจจำนวนรายการ
3. ระบุเหตุผลอย่างน้อย 5 ตัวอักษร
4. กด **รวมข้อมูลจาก Backup**

ระบบจะตรวจ schema และ checksum ก่อนเสมอ การกู้คืนเป็นแบบ merge-only จึงไม่ลบแถวปัจจุบัน ข้อมูลหลักที่มี ID เดิมจะถูกอัปเดต ส่วน Review และ Audit ที่มี ID เดิมจะไม่ถูกเพิ่มซ้ำ

## ข้อควรระวัง

- ห้ามแก้ JSON ด้วยมือ เพราะ checksum จะไม่ตรง
- ทดสอบไฟล์ล่าสุดหลังดาวน์โหลด โดยเลือกเข้า validator อย่างน้อยเดือนละครั้ง
- เก็บอย่างน้อย 3 รุ่น: ล่าสุด, รายสัปดาห์ และก่อนเปลี่ยน schema
- การกู้คืนไม่แทนการสำรอง Google Sheet โดยเจ้าของบัญชี
- หากไฟล์เกิน 5 MB ให้สำรอง Google Sheet โดยตรงและวางแผนย้ายฐานข้อมูลก่อน restore
