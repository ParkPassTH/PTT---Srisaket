# คู่มือผู้ปฏิบัติงานทะเบียน ICS

## 1. ตรวจความพร้อมก่อนทดสอบ

เข้าสู่ระบบและเปิดเมนู **การเชื่อมต่อ** สถานะฐานข้อมูล, LINE Messaging API และระบบ AI ต้องเป็น `พร้อม` หากรายการใดขึ้น `ต้องตั้งค่า` ให้แก้ Environment Variables ใน Vercel แล้ว Redeploy

## 2. เพิ่มเกษตรกรและแปลง

1. เปิด **เกษตรกรและแปลง** แล้วกด **เพิ่มเกษตรกร**
2. กำหนดรหัสสมาชิกที่ไม่ซ้ำ เช่น `M001` และชื่อจริง
3. กด **เพิ่มแปลง** ใต้ชื่อสมาชิก ระบุชื่อแปลงและพืชหลัก
4. ให้เกษตรกรส่ง `ลงทะเบียน M001` ใน LINE
5. เมื่อ LINE ตอบว่าเชื่อมสำเร็จ จึงเริ่มส่งข้อความเสียง

ไม่ต้องเปิดหรือแก้ Google Sheet ด้วยตนเอง ระบบจะสร้าง/อัปเดตแถวใน `Farmers` และ `Plots`

## 3. บันทึกกิจกรรมด้วยเสียง

ข้อความเสียงควรบอกชื่อแปลง พืช กิจกรรม สิ่งที่ใช้ และปริมาณเมื่อเป็นการเก็บเกี่ยว หลังระบบถอดเสียง:

- ผลเบื้องต้นปกติ: เกษตรกรส่ง `ยืนยัน <เลขที่รายการ>`
- ข้อมูลไม่ครบหรือพบความเสี่ยง: รายการเข้าสู่งานตรวจสอบ
- ประมวลผลไม่สำเร็จ: ตรวจ Production Logs และส่งเสียงใหม่หลังแก้สาเหตุ

## 4. งานตรวจสอบ

เปิดรายละเอียด อ่านข้อความถอดเสียง ข้อมูลที่สกัด เหตุผลจากกฎ และประวัติ ก่อนเลือก:

- **ขอข้อมูลเพิ่ม** — บันทึกสถานะรอเกษตรกร และส่ง LINE หากบัญชีผูกไว้
- **ยืนยันความเสี่ยง** — ปิดการตรวจด้วยสถานะไม่รับรอง
- **อนุมัติรายการ** — ใช้เมื่อเจ้าหน้าที่ตรวจหลักฐานครบแล้ว

ทุกการตัดสินใจต้องระบุเหตุผลอย่างน้อย 5 ตัวอักษรและถูกเก็บใน audit trail

## 5. ล็อต คลัง และ QR

กิจกรรมสร้างล็อตได้เมื่ออนุมัติแล้วและมีพืช แปลง ปริมาณ และหน่วยครบ เปิด **ล็อตและคลัง** แล้วกด **สร้างล็อต** จากนั้นสามารถ:

- เปิดหน้าตรวจสอบสาธารณะ
- ดาวน์โหลด QR PNG เพื่อติดฉลาก
- เปลี่ยนเป็นส่งแล้ว ยกเลิก หรือเรียกคืน โดยต้องระบุเหตุผล

หน้าสาธารณะแสดงเฉพาะข้อมูลล็อตที่ปลอดภัย ไม่แสดงชื่อหรือรหัสเกษตรกร

## 6. รายงาน

เปิด **รายงาน** และดาวน์โหลด CSV ไฟล์เป็น UTF-8 พร้อม BOM จึงเปิดภาษาไทยใน Excel หรือ Google Sheets ได้ การดาวน์โหลดถูกบันทึกเป็น audit event

## 7. การแก้ปัญหาเร็ว

- ไม่พบรหัสสมาชิก: ตรวจว่าเพิ่มสมาชิกแล้วและสถานะเป็น Active
- รับเสียงแต่ AI ล้มเหลว: ตรวจ `AI_PROVIDER`, API key, model และ Vercel Function Logs
- ข้อมูลไม่ขึ้น Google Sheet: ตรวจ `DATA_DRIVER=google-sheets`, service-account email, private key, Sheet ID และสิทธิ์ Share
- LINE ไม่ตอบ: ปิดข้อความตอบกลับอัตโนมัติของ LINE OA, เปิด Webhook และตรวจ channel secret/access token
- สร้างล็อตไม่ได้: ต้องอนุมัติกิจกรรมก่อนและข้อมูลเก็บเกี่ยวต้องครบ
